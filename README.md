### About

I'm the **Founding Frontend Developer at Hosté Technology**, a Nigerian premium event-staffing marketplace, where I'm building a three-sided platform (brands, workers, admin) from the ground up. I'm also **Frontend Developer & Bootcamp Lead at Appclick ICT Academy** in Abuja, where I mentor 30+ developers coming up through the program.

I work across the stack — **React / Next.js / TypeScript** on the frontend, **Node.js / Supabase / Firebase / PostgreSQL** on the backend — and spend a lot of time wiring LLMs (**Claude, Gemini, OpenRouter, Ollama**) into real products, not demos.

- 🌍 **Location:** Abuja, Nigeria
- 🏢 **Currently:** Founding Frontend Developer @ Hosté Technology · Bootcamp Lead @ Appclick ICT Academy
- 🎓 **Education:** B.Tech, Front-End Development — Appclick Academy
- 📜 **Certifications:** IBM AI Fundamentals · Advanced Backend Engineering (BeTechified, Global Tech Village)
- 🌱 **Currently exploring:** deeper LLM-orchestration patterns, offline-first mobile architecture, and AI features that hold up in production
